# 站內通知數字徽章

更新日期：2026-11-09。使用者要求增加新作業及學生提問的紅色數字徽章，續要求複製連結使用按鈕與重疊圖示。本文件記錄實作政策與驗收。

## 顯示與計數

- 紅底白字圓形徽章，0 不顯示、1–99 顯示數字，超過 99 顯示 99+，可存取名稱與提示保留完整數量。
- 學生：通知其有效修課中已發布、可在「測驗與作業」清單列出的線上測驗與 PDF 作業；教師草稿及已關閉評量不計入。權重連動表是現有清單篩選依據，不另建立評量資料。
- 教師／助教：通知其任教課程內學生提出、本人尚未看過的課程問題。徽章代表「未讀」，不是「未答覆」；助教看過不替教師消除，已回覆問題若教師尚未看過仍可提醒。
- 課程管理導覽顯示所有本人課程未讀合計；測驗與作業導覽顯示本人學生課程的新評量合計。課程卡片顯示本課總數與「新測驗／作業」「學生新提問」直接入口；課內對應頁籤顯示各類數量。手機選單按鈕亦顯示合計，桌機仍隱藏手機選單。
- 正式課程角色逐課判斷，平台管理員不繞過修課權限。封存課程與無效成員不計入；學生體驗不顯示或寫入正式通知。
- 初次啟用沒有歷史已讀證據，現存符合條件且未讀的項目也會顯示；不推造過去曾閱讀。發布前草稿不提醒；同一項目改標題／重新發布不重設已讀。

## 已讀與更新

- 已讀保存在資料庫，以「使用者＋種類＋項目 ID」唯一，重新登入與其他裝置沿用；不只存在瀏覽器。
- 成功載入並渲染測驗／作業清單後，僅將當次顯示的已發布評量標為本人已讀。成績總覽不消除作業通知。
- 教師／助教成功載入並渲染問答清單後，僅標記本頁項目；每頁 20 筆，分頁外項目及載入後才新增的問題不會被全部清空。直接開啟作答頁不額外消除其他項目通知。
- 寫入可重送，伺服器驗證整批項目皆屬於本人可接收通知的資料；不得指定其他使用者，無權或混入未知項目整批拒絕。每批最多 200 筆，前端分批處理。
- 登入、切換帳號／視角、路由切換、視窗重新聚焦／回到前景時刷新；前景每 30 秒更新。背景停止輪詢請求。切換身分時立即清空舊數字並忽略舊請求延遲回應。
- 清單提供「重新整理測驗與作業」「重新整理問題」按鈕。使用者停留清單時若另有新增，可重新整理看新項目；導航徽章本身不代表清單已自動插入新內容。
- 此為站內數字提醒，不發送電子郵件、瀏覽器推播或站外訊息，不建立通知中心。

## 複製連結

教材頁「分享連結」旁固定顯示「複製連結」實體按鈕，使用 Lucide Copy 重疊方框圖示；不再只有文字連結或限原生分享可用時顯示。保留固定資源網址、成功提示與無剪貼簿權限時手動選取網址的備援。

## 資料與 API

- 025_notification_reads.sql 新增 notification_reads；舊教材、作答、成績、私人問答及有效學習時間不更動。
- GET /api/notifications：本人 assignments／questions／total 與各課 courseId／分類／合計；查詢不標記已讀。
- POST /api/notifications/read：kind 為 quiz／report／question，ids 為已顯示項目 ID 陣列；沿用 Cookie／CSRF。伺服器取得登入者，不接受自訂 userId。
- 已讀寫入鎖住相關課程／成員／帳號，避免撤權競態，主鍵與 ON CONFLICT 保證同時重送不重複。
