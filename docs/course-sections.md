> 2026-11-03 使用者已改為「取消班別，只保留課程」。本文件保留原分班實作與驗證歷史，需求效力由 [單一課程層級規格](course-only-spec.md) 取代。取消班別目前只完成規格與影響評估，程式／DB 尚未移除；不可依本文刪班流程執行資料轉換，以免刪除小組與歷史關係。

2026-10-30 現行行為；延伸課程工作區，不改測驗／PDF／案例與加權成績政策。

- 課程 > 課程學員／分班／小組：教師／助教建立與編輯班別名稱、上課時間／說明，並安排有效學生。一位學生在同一課程至多一班，可未分班；同一帳號在不同課程可屬不同班別。
- 編輯班別時，選入其他班的學生會調入本班；取消原本班學生會改為未分班。只有班別實際改變的學生會結束其原小組有效成員關係，歷史 left_at 保留。
- 新增／編輯小組必須指定本課班別，只能選同班有效學生；一位學生至多一個有效小組。小組名稱在班內唯一，不同班可同名。原有未分班小組保留，編輯時才要求指定班別，不自動推斷上課時間或安排真實學生。
- 課程 > 資源／講義：上傳與後續調整均可選「全部班別共用」或「限某班」。共用僅指本課程有效成員，並非公開檔案或跨課程共用。
- 教師／助教可管理及下載本課所有班別資源；學生僅可列出／下載共用及本人班別資源，未分班僅可使用共用資源。課程摘要的資源數也遵守此範圍。偽造資源 ID 不能繞過下載檢查；未授權請求不增加下載次數。
- 教學人員的學生練習視角只看共用資源，不能管理分班／小組／資源範圍。封存課程禁止上述寫入；學員加入與課程角色調整仍限擁有教授，改為非學生角色會清除班別並結束有效小組關係。
- 班別不是新課程。測驗、PDF 作業、案例及成績仍綁原 course_id，本輪不新增依班派題或班別成績篩選。測驗／PDF 仍個別提交。

## 2026-10-30：逐人移動班別

學生分班名單可逐列選擇班別或未分班，再按「儲存調班」。班別表單只維護名稱／時間，省略 Members 表示不變更名單，明確 Members 仍保留原整班 API 相容。新 PUT /api/courses/{course}/classmates/{student}/section 接收 sectionId 與必要 expectedSectionId（可為 null）；核對原班別，衝突 409 後可重新載入。操作沿用教師／助教權限與課程鎖，同課班別／有效學生檢查，封存與 practice 禁止。只更動目標學生並結束本課原有效小組關係，作答及成績保留；無 schema 變更。此調整取代原 UI 透過整份勾選名單調班的方式，未新增批次搬移。

## 2026-10-30：班別刪除

卡片垃圾桶先 GET /api/courses/{course}/sections/{id}/deletion，確認學生人數、小組名稱與刪除關係紀錄後，以 DELETE 同路徑帶 expectedToken。token 為名稱／時間／學生／小組與關係／資源的快照 hash，內容已改則 409。空班可刪；有學生者改未分班，有小組者經確認刪組與組員關係。保留課程資格、帳號、作答及成績。若有專用資源要求先移轉範圍，不自動共用；若小組有作業紀錄則拒絕。有效教師／助教限定，封存與 practice 拒絕，課程及班別鎖、交易、稽核及 FK 衝突保護，無遷移。
