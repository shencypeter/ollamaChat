# 課程功能結構與線下評分管理

2026-10-29 使用者要求將課程功能依下列層級整理，並確認每項成績需可設定權重。

```
課程
├─ 教學資源／講義：上傳、下載、下載次數
├─ 同學：課程學生名單、小組設定
├─ 作業管理
│  └─ 個別作業 → 提問（教師／助教決定是否公開）
├─ 考試管理
│  └─ 個別考試 → 排行榜（名次／學號）
└─ 評分管理：線下作業、小考、期中考試等得分與加權平均
```

課程導覽使用 `?section=resources|students|assignments|exams|grades`，可重新整理或直接連結。預設資源頁。原作業建立／規準／提交與檢閱流程歸入作業管理；獨立考試原閱卷流程保留，排行榜另有表格與排序入口。完整排行榜仍限教師／助教，不因本次導覽變更公開其他同學成績。

## 線下評分

- 教師／助教可建立或編輯評分項目，包含名稱、類型（線下作業／小考／期中／期末／其他）、滿分與正數權重。滿分最多兩位小數，權重最多三位；可用 30／70 或 3／7，無須合計 100。
- 選擇項目逐人登錄得分，只接受課程有效學生，且得分介於 0 與該項滿分。滿分不能改成低於已登錄得分。空白可清除得分，0 需明確輸入；清除仍保留遞增版本，舊分頁無法重新寫回。
- 得分儲存後本人立即可見。學生只看本人各項得分、本人平均與全班／各項匿名平均；教師／助教看全班。學生體驗只看統計，不讀真學生得分也不建立虛構成績。非成員拒絕，封存課程唯讀。
- 個人平均：對已登錄項目計算 `Σ(得分 ÷ 滿分 × 100 × 權重) ÷ Σ(已登錄項目權重)`。未登錄／已清除項目不計入分母；明確 0 分照常計入。
- 全班平均：有至少一項得分的有效學生，其個人加權平均的算術平均；沒有得分者不計入。每項全班平均則對該項已有得分學生，算百分制平均。先用完整 decimal 精度計算，顯示時四捨五入兩位小數。
- 例如線下作業滿分 20、權重 30、得分 10，期中滿分 100、權重 70、得分 80，個人平均為 71。另一位只有作業 20 分，其平均為 100，兩位全班平均為 85.5。
- 本頁只登錄得分，不建立線上題目、作答或 AI 評閱。與作業成績／線上考試表分開，不自動匯入那些成績，避免重複計算。權重目前全項一起計算，不做類別的第二層權重。
- 每位同學分別儲存，儲存一人不會丟失其他未儲存輸入。切換登錄項目、課程功能、離開與重新整理時提醒未存修改；取消離開應保留編輯。

## 資料與 API

007_offline_gradebook.sql 新增 course_grade_items、course_grade_scores，既有 001–006 不改動。分數空值為清除紀錄的 tombstone，保留版本而不是刪列；只有非空值納入平均。寫入有 course 列鎖、交易與版本檢查；API 使用原 Cookie／CSRF 及後端課程授權。稽核只存操作與識別碼，不記學生答案或憑證。

- GET `/api/courses/{course}/gradebook`：項目、授權可見學生與得分、個人平均及匿名班級統計；一致性讀取。
- POST `.../gradebook/items`、PUT `.../items/{id}`：教師／助教新增與編輯項目，編輯需要 expectedVersion。
- PUT `.../items/{id}/score`：studentId、score（可空）、expectedVersion。首次版本 0；過期回 409。學生與 practice 寫入 403。
- GET `/api/courses/{course}/classmates`：有效課程成員讀取有效學生名單（姓名／學號，不提供電子郵件或成績）。分組與原課程成員管理權限維持。
