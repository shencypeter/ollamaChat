目前課程頁有「課程資源／講義」「課程學員／小組」「測驗與 PDF 作業」「測驗／作業成績」「優良作業觀摩」「案例學習」，尚無獨立課程問答頁籤。現有作業提問預設私人，教師／助教可公開問題與答覆；新增課程問答不能將舊私人問題自動公開。

現有手機導覽設定於 760px 以下顯示，實作須檢查 CSS 優先序與實際桌面呈現，確保桌機不顯示手機專用灰色漢堡按鈕。

## 三、資源連結分享

- 資源閱讀頁標題旁提供「分享連結」，分享站內目前教材的固定網址。
- 有瀏覽器原生分享能力時可開啟分享面板；無支援或使用者需要複製時提供複製連結及成功／失敗訊息。
- 複製的是資源頁網址，不含登入憑證、私有附件存取 token 或使用者識別參數。
- 接收者仍須登入且具有本課資源存取權。分享不改變資源可見性，不建立匿名公開教材或跨課共用資源。
- 非計時支援格式亦應有可分享的資源入口，不為分享強迫啟動學習計時。

## 四、按讚、留言與統計

資源內容下方提供「讚 12」「留言 3」及留言區。以課程資源 ID 作為互動歸屬，不以完整網址字串作主鍵；不同查詢參數、入口或分享方式進入同一資源，計入同一份統計。

- 具有本課有效存取權的成員可讀取該資源互動；正式模式可按讚及留言。
- 每位成員每份資源最多一個有效讚，可取消；重送請求不重複累加，並顯示本人是否已按讚。
- 留言顯示作者、時間與純文字內容；列表應分頁，數量為有效留言總數，不是目前頁筆數。
- 不將開啟頁面、下載或分享按鈕點擊當成按讚或留言。既有下載次數及有效學習時間分開顯示，不重算。
- 寫入由伺服器驗證課程、資源、登入者及模式；不可偽造作者或把留言掛到另一課資源。
- 練習／學生體驗不得寫入正式社群互動；封存課程保留授權唯讀，停止新增互動。

留言編輯／刪除、教師管理、字數與分頁上限等未於畫面提案逐項確認的細節，實作時採最小必要設計並記錄採用值，不擴充通知、附件、巢狀討論或站外社群功能。

## 五、學員檔案與資源互動紀錄

學員檔案新增「資源互動紀錄」，每項至少包含課程、資源名稱、互動類型、最近互動時間與可授權開啟的資源連結。類型涵蓋閱讀／觀看、按讚及留言。

- 本人可看自己有有效學生資格課程的跨課紀錄；教師／助教只能看所任教課程內學員的紀錄。
- 平台管理員不因全域管理權取得所有學員互動；學生不得查看其他學生的完整互動檔案。
- 閱讀／觀看沿用既有正式有效學習紀錄，並維持實際時間與影片內容時間的既有意義；無紀錄不推造已讀。
- 正式與練習資料分離；不在檔案曝光私人作業問題、答案、草稿或未公布成績。
- 可依課程與互動類型篩選，資料分頁；取消按讚後不得仍顯示為目前有效按讚。
- 顯示互動事實，不將其判定為理解、通過或完課。

## 六、課程問答

在課程頁新增獨立「課程問答」頁籤，與教材留言及原作業私人提問分開。

- 本課學生送出問題後即對同課有效成員可見，答覆前不隱藏、不要求教師先公開。
- 未答覆顯示「待回覆」；教師或助教回覆後顯示「已回覆」。教授在本課具有授課教師角色時可回覆。
- 顯示問題作者、提問時間、問題內容、回覆者及回覆時間，問題與回覆均純文字呈現。
- 學生不得透過 API 回覆為教師、替換他人作者或讀取其他課問題。平台管理權不繞過課程授權。
- 封存課程唯讀；練習模式不建立正式問題或回覆。
- 原「作業提問與答覆」保留預設私人及既有公開流程，舊資料不搬移或批次公開。

問答回覆數量、編輯及刪除等未逐項確認的細節由實作記錄明確說明；本批不自動加入電子郵件通知或 AI 回覆。

## 七、RWD 與驗收

1. 桌機不顯示手機專用灰色漢堡選單；手機可展開與關閉導覽，按鈕狀態及可存取標籤一致。
2. 帳號與課程設定使用各自名稱／圖示；測驗作答、教師給分、課程成績入口可清楚區別。
3. 分享同一資源的不同入口網址，接收者登入後開啟同份教材；未修課者仍拒讀。
4. 重複送出按讚及多分頁操作不重複計數；取消後統計與本人狀態一致。
5. 留言顯示及總數一致，HTML 當純文字；跨課、冒用作者、練習及封存寫入遭拒。
6. 本人跨課互動、教師課內學員互動的範圍正確；其他學生及未任教管理員無法取得私人檔案。
7. 學生提問後，另一位本課成員在未回覆時即可看到；教師／助教皆能回覆並變更為已回覆。
8. 舊私人作業問題保持私人；課程問答、教材留言與作業提問不互相混計。
9. 桌機與 390px 手機無橫向溢出，長名稱、留言及連結正常換行；按鈕可用鍵盤操作。
10. 原教材計時、倍速門檻、評分公布、匿名觀摩與課程權限回歸正常。

## 九、2026-11-09 實作採用值與 API

本節取代第八節「尚未修改產品」的現行狀態。新增 024_resource_interactions.sql：resource_likes、resource_comments、course_questions；舊作業問題、教材、學習時間與成績不搬移、不重算。

- 教材頁顯示分享、按讚與留言；原生分享外提供複製連結，複製失敗顯示可選取網址。一般不可計時格式亦可由教材卡片進入同一固定網址，提供既有預覽／下載，不啟動計時。
- 每人每資源一讚，PUT 明確指定 liked true／false，可重送且可取消。留言 1–4000 字純文字；本批只新增及分頁閱讀，未加入編輯、刪除、附件或通知。
- 留言與提問使用客戶端隨機 UUID 作請求識別；同作者、同目標、同內容重送不重複建立；識別碰撞回 409，作者由登入者決定，額外作者欄位回 400。
- 課程問題 1–8000 字，回覆 1–16000 字。每題一份目前答覆，教師與助教均可修訂；expectedVersion 防止覆寫他人剛更新的答覆。409 保留未存文字，畫面可明確重新載入。尚未支援多回覆串、問題編輯／刪除與通知。
- 留言、問答、互動檔案皆每頁 20 筆。資源讚／留言統計為全量有效筆數，不因分頁改變；以 resource ID 歸屬，網址查詢參數不影響。
- 互動檔案按「資源＋互動類型」彙整；多次留言顯示最近時間，閱讀／觀看依正式有效計時合計，取消讚即不列目前有效讚。本人由帳號設定的學員檔案連結或既有學員資料頁查看；師／助教由課程學員名單進入，只限指定本課。可依課程／類型篩選。
- 封存與練習模式互動唯讀；互動檔案只提供正式模式。問答本課有效學生可問，師／助教可答；管理員沒有額外教學資料權。寫入交易鎖住成員／課程／資源，避免封存或撤權與寫入競態。
- 課程設定為現有學員／小組、教材、測驗與作業管理的集中入口，不新增權限；帳號設定與課程設定使用不同圖示。評閱及成績頁改名沿用同一份原評量資料。

## 十一、課程討論區（2026-11-11）

本節取代前述「課程問答」的單題卡片介面，資料與授權原地擴充，不搬到平行論壇。

- 左側直接列出本課全部討論串與主題、作者、回覆數、讚數及關閉狀態；右側顯示目前選取討論。頂部及瀏覽到底皆提供前一篇／後一篇，手機改為上下排列。
- 學生、教師及助教皆可發起和回覆；教師／助教依本課角色顯示 Moderator badge。平台角色不能繞過課程成員授權，也不能由客戶端指定作者或 badge。
- 討論串沿用 `course_question_votes`；新增 `course_question_reply_likes` 供一般回覆每人一讚並可取消。已關閉討論仍可閱讀及按讚，但不能新增回覆。
- 只有本課有效教師／助教能關閉或重新開放。封存課程及學生體驗唯讀；跨課 QuestionId／ReplyId 皆拒絕。
- 031 新增 200 字主題並以舊內容摘要回填；032 保留舊版 API 部署窗口相容，空主題由新版讀取時回退內容摘要。舊單份教師答覆、一般回覆、投票、PDF 附件及通知識別均保留。

新增／調整 API：`GET questions?all=true` 供課內側欄、`GET questions/{id}/replies?all=true` 供完整閱讀、`PUT questions/{id}/replies/{replyId}/like` 設定回覆讚；原 lock 端點維持教師／助教限定。後端 228、前端 78 與 production build 通過；7173 public 已套用 031–032，服務重啟與真實瀏覽器驗收另行進行。
