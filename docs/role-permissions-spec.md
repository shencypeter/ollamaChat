# 平台管理權限與課程角色規格

## 2026-11-10 小組 PDF 權限

教師與具 assessments 權限的助教管理分組及作業。具有 grading 權限者可查看個別互評、表態、調整原因，並退回、批改及發布。學生只可看本組繳交，填寫自己的回覆與表態；組長的額外權限為正式繳交。詳見 [分組與 PDF 作業](group-pdf.md)。


決策日期：2026-11-03。使用者採用「平台管理權限／課程角色分離，建立課程為獨立權限」。後續使用者已要求實作，2026-11-03 完成程式、015 遷移與 5097 預覽部署。平台角色現為 Administrator／Member，建課資格獨立；以下規格已實作。

## 角色與權限

| 層級 | 定義 | 權限邊界 |
| --- | --- | --- |
| 平台管理權限 | 管理員、一般成員 | 管理員負責平台帳號、管理權限、建課資格、全域系統設定及稽核；一般成員沒有平台管理權。 |
| 建立課程權限 | 獨立的可建立課程資格 | 由管理員授予／撤銷，不由「教授」名稱或某課程教師角色推導。管理員也須明確具有建課資格才可建立課程；初始化與遷移需明訂初始值。 |
| 課程角色 | 授課教師、助教、學生 | 以本人在指定 course_id 的有效成員關係為準；一人每課一個角色，不同課程可不同。 |
| 課程擁有者 | 課程屬性 owner_user_id，非另一套平台角色 | 沿用擁有者管理本課成員／角色的責任；必須保有本課有效授課教師角色。 |

平台成員頁不再把「教授／教學助理／學生」當全域授權角色。若未來記錄職稱或身分，僅為個人資料，不用來推導權限。一般成員可由課程擁有者安排為授課教師、助教或學生，不受原平台身分類型限制。

例：同一帳號可在甲課為助教、乙課為學生，且完全沒有平台管理權；另一帳號可同時是平台管理員與某課學生，其課程內操作仍按學生角色。登入後顯示可管理的平台功能，進入課程後明確顯示「本課程角色」，不將多層權限混成單一角色標籤。

## 授權規則

- 有建課資格的有效帳號可建立課程，建立者成為該課擁有者與有效授課教師；無資格者即使在別課授課也不能建新課。
- 撤銷建課資格只阻止未來建課，不移除既有課程擁有權／教師資格。撤銷平台管理權也不改動課程角色。所有平台權限授予／撤銷限管理員，保留稽核；避免撤銷／停用最後一位有效管理員造成無法維護。
- 課程擁有者安排本課有效帳號與角色；保留不可把擁有者降為助教／學生的約束。課程教師／助教的出題、內容維護、檢閱正式提交、評分及小組管理沿用既有分工；不因取消平台教授角色額外開放成員管理給助教。
- 管理員資格本身不等於加入所有課程，不自動取得其他課程教師權限、學生答案／私人草稿／PDF／成績。要執行課程教學功能須具該課有效角色。全域帳號／參與關係的管理資訊與教學內容讀取分開核對，不提供隱藏的管理員教學內容繞過權限。
- 各課程資源、評量、成績與學員權限獨立，課程同名、同一教師或具有建課資格都不授予跨課讀取；不提供跨課程資源共用。
- 教師／助教的學生體驗依所在課程有效教學角色啟用，保留本人身分、正式／練習資料與計分隔離。真實學生不因其他課為教師而把本課正式提交誤標為練習；同課學生角色也不能自我切換為教學角色。
- 學生基本資料完成要求、預設首頁及導覽應依其課程需求／操作情境判定，不再只依全域 Student／Professor 旗標決定。封存課程、帳號停用、CSRF、提交期限、成績發布前保密等政策維持。
- 後端逐操作驗證管理權、建課資格與課程角色；不能只改導覽顯示或靠前端傳入角色。權限變更後須更新／失效相關授權快取或登入 claims，避免舊 Cookie 繼續持有撤銷權限。

## 介面與既有管理頁調整

- 「平台成員」分別呈現「平台管理權限」及「可建立課程」，不在此設定全域教授／助教／學生。課程角色於各課程成員頁安排，清楚顯示目前所屬課程。
- 主導覽的平台管理入口依管理員資格，建立課程按鈕依建課資格；課程教學入口及學生操作依各課有效角色。同一帳號可同時擁有不同課程操作入口。
- A2 平台帳號／權限、A5 全域 AI 模板、A6 系統參數／稽核依管理員資格；A3／A4 的課程案例與私密標準答案維護依課程教師／助教角色。現有 StudioAdminController 混用全域 Professor 保護，實作時需拆分全域設定與課程教學路由／授權，不將整個 A 區單純改成管理員繞過。
- T1–T4 名單、歷程、統計／匯出按有效課程教學角色，學生 S 流程按有效課程學生角色；案例標準答案仍不因平台管理員資格自動公開。

## 驗收

- 一般成員可在甲課當助教、乙課當學生，權限不串用；未加入丙課不可讀取其資源／學生紀錄。
- 無建課資格的管理員不能建課；有建課資格的一般成員可建課並成為該課擁有教師，但不可管理平台帳號。
- 管理員未加入課程時不可藉管理 API 讀其標準答案、私人草稿、PDF 或正式成績。
- 撤銷管理權／建課資格後舊 session 不可繼續執行被撤銷操作，原課程角色與擁有權不受誤改；最後管理員保護有效。
- 原有正式／練習作答、私密標準答案、批改發布、課程隔離及封存限制持續通過。多課混合角色的首頁／導覽與資料完成流程可正常操作。
