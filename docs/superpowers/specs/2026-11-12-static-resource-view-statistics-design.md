# 靜態教材點閱與影片觀看統計設計

日期：2026-11-12  
狀態：已實作並驗證

## 行為

- 影片與 YouTube 教材維持逐位學生的正式累積觀看時間、內容時間、播放速度及最近觀看。
- PDF、圖片、Office、文字及其他非影片教材的教師統計不顯示閱讀時間，改顯示曾點閱學生名冊、每人點閱次數、最近點閱、總瀏覽次數及既有讚數。
- 每次正式學生進入靜態教材頁記一次點閱。同一請求識別重送不重複；教師、助教、學生視角預覽、封存課程與非本課成員不計入。
- 靜態教材原有學習 session 與測驗教材門檻暫時保留相容，不在教師點閱名冊中顯示或比較時間。
- 教材互動區的留言數量與按讚按鈕採相同高度、邊框及水平排列；留言數仍是狀態顯示，不冒充可操作按鈕。

## 資料與授權

- Migration 034 新增 `resource_views(id, resource_id, user_id, viewed_at)`；`id` 提供冪等寫入，資源刪除時連帶刪除點閱。
- `POST /api/courses/{course}/resources/{resource}/views` 只為本課正式 active 學生寫入；其他有效角色安全地不寫入。
- 既有 statistics 端點依伺服器辨識的媒體類型回傳 `isVideo`，並加入 `viewCount`、`viewedCount`、`likes` 與逐人 `views/lastViewedAt`；教師／授權助教權限不變。
