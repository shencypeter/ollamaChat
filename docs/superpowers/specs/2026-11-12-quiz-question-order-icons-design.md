# 測驗題目排序圖示設計

## 目的

將課程測驗編輯器中「拖曳／上移／下移」三個文字按鈕改成精簡圖示，降低題目標頭的視覺雜訊，特別改善窄螢幕排列。

## 設計

- 沿用專案既有 `@lucide/vue`，不新增 Font Awesome 依賴。
- 拖曳使用 `GripVertical`，上移及下移使用 `ArrowUp`／`ArrowDown`。
- 三者使用既有 `icon-button` 樣式，保留可辨識的中文 `aria-label` 與 `title`。
- 拖曳事件、按鈕停用邏輯、題目排序資料及儲存格式完全不變。
- 只調整測驗／作業共用題目編輯器，不修改單元活動或單元卡片的排序控制。

## 曾考慮方案

- 新增 Font Awesome：圖示可符合指定名稱，但會為三個按鈕增加第二套圖示依賴，未採用。
- 使用 CSS／Unicode 符號：不增加依賴，但跨平台外觀與可讀性較差，未採用。
- 沿用 Lucide（採用）：與全站一致、改動最小，並能保留完整可存取性。

## 驗收

- 題目標頭不再顯示「拖曳／上移／下移」文字。
- 輔助科技仍能讀出三個操作名稱。
- 上移、下移及拖放排序行為維持既有結果。
