# 授課日期、教師摘要與教材整理規格草案

日期：2026-11-09。狀態：新欄位／查詢未實作；播放器、標籤、逐字稿現況見[教材文件](course-materials.md)。依[會議入口](meeting-2026-11-06-gap-spec.md)D3定案。

## 第一批建議範圍

沿用每課獨立course_resources，增加授課日期與教師摘要，保留一份教材一個名稱／日期／摘要。現有display_title就是教材／回放主題，不再新增含義重複的course_title。多份同日教材可依授課日期分組，但沒有隱含共用摘要或新「班級」層。

若教授要求「一堂課含多份講義、多影片且共同摘要／逐字稿」，應改為課內教學單元＋資源關聯，不強行用重複日期當單元ID；此升級待D3，不在本輪默認新增。

| 欄位 | 規則／第一批建議 | 現況 |
|---|---|---|
| course_id | 既有課程，不可跨課共用或重新指定搬移 | 已有 |
| display_title | 既有200字名稱，回放必填；課程主題沿用此欄 | 已有 |
| teaching_date | 可空，YYYY-MM-DD的授課日，不含時區／鐘點，不設必須過去日期 | 新增提案 |
| summary | 教師提供純文字，選填，建議最多10,000字；空白可清除 | 新增提案 |
| metadata_version | 上述日期／摘要共同獨立版本，預設1 | 新增提案 |
| tags | 沿用10個各30字及週次正規化；首批不另設必選分類字典 | 已有 |
| created_at | 伺服器上傳／新增時間，不能被授課日期覆蓋 | 已有 |
| resource_type／影片ID | 沿用檔案或YouTube及已驗證影片ID | 已有 |
| transcript／版本 | YouTube已有最多100,000字，與摘要不同 | 已有 |

摘要不由AI產生、不自動從逐字稿截取。編輯摘要／日期不改bytes、影片ID、標籤／名稱／逐字稿版本、原計時、門檻與成績。原資料授課日期預設null、摘要空；不以上傳日、檔名、週次tag推造。

## 介面與查詢

- 新增檔案／回放表單加入授課日期及摘要；回放仍可同時貼逐字稿。教師／助教可事後修改，學生唯讀。
- 卡片顯示授課日期與上傳日期的明確標籤；未填顯示「未指定授課日期」，不能混成今天。摘要可收合閱讀，播放頁在影片附近分列摘要／逐字稿。
- 支援日期起迄（含兩端）、標籤、名稱／檔名／摘要搜尋的交集；空日期在不設日期條件時仍出現，另可篩「未指定日期」。若同時要求日期區間與未指定，回400或UI禁止，不默默忽略條件。
- 建議提供依授課日期新到舊／舊到新及原上傳日期新到舊；同日以created_at、id穩定排序，空日期排最後。日期分組只用實際日期，不推算學期第幾週；週次仍由教師tag標記。
- 授課日期為日期值，不做UTC轉換，不因學生瀏覽器時區顯示前一天。摘要／逐字稿以純文字呈現，不解譯HTML。

## 資料、API與權限提案

以新向前遷移在course_resources新增teaching_date(date null)、summary(text)、metadata_version；不修改已套用001–020。新增表單可帶欄位，舊客戶端省略仍相容。

GET /api/courses/{course}/resources增加teachingDate、summary、metadataVersion與查詢teachingFrom／teachingTo／undated／sort；既有q、tag仍有效。避免將完整逐字稿塞進全部列表；逐字稿沿用獨立端點。

PUT /api/courses/{course}/resources/{id}/metadata提交teachingDate（null可清除）、summary（空字串可清除）、expectedVersion。欄位需明確提供，避免省略造成誤清空；非法日期、from>to、摘要超長400，版本過期409且保留使用者輸入。教學端維持原版本重載確認後才覆寫。

寫入限本課教師／助教教學模式、未封存；讀限本課有效成員。平台管理員不繞過。資料變動／稽核同交易，稽核僅版本與ID，正文不記日誌。圖片／PDF／影片既有預覽、下載計次與時間統計授權不變。

## 驗收

| ID | 情境 | 預期 |
|---|---|---|
| MAT-01 | 上課前一週上傳、授課日填未來 | 上傳日與授課日分開呈現 |
| MAT-02 | 舊教材無授課日期／摘要 | 不回填假日期；可於未指定篩選找到 |
| MAT-03 | 日期＋tag＋q查詢 | 僅回交集，摘要可搜；跨課仍拒絕 |
| MAT-04 | 學生不同瀏覽器時區 | 授課日不偏移；上傳時間仍按既有顯示 |
| MAT-05 | 同日多檔與影片 | 同日期可分組，排序穩定，不被誤認同一資源 |
| MAT-06 | 摘要HTML／超長／清空 | 純文字、超長拒絕、可清空，逐字稿不受影響 |
| MAT-07 | 兩人同改、學生／practice／封存寫入 | 過期409或拒絕，保留未存輸入 |
| MAT-08 | 改摘要／日期後重新讀教材與門檻 | bytes、影片ID、下載次數、既有雙時間及門檻不重算 |

本規格不擴充影片監控、AI摘要、字幕抓取、跨課分享、影音上傳串流或教材完讀／通過判定。
