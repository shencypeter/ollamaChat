## 案例與回饋

四階段固定為病前功能、疾病病程、功能評估結果、心理社會條件。每階段最多 16000 字元，明確儲存四階段草稿；有未存修改時離頁提醒。只向 AI 送出目前已存、非空白、本人答案版本，不使用一般對話記憶／其他學生／其他階段答案。

新案例採獨立 studio 表，不重新開放原作業 ai-feedback API。新回饋只含 summary、supportedPoints、improvements、nextSteps；不含 score、thinking、raw response 或 requestInspection，嚴格解析未知欄位及缺欄位失敗。固定提示要求文字回饋、不提供分數、不代寫、只用案例原文核實，教師清單與結構提示不是案例事實。管理模板只調整風格，不能移除固定規則。

案例素材／結構提示／重點清單每次儲存新增不可改寫版本，發布指標與草稿指標分開；未存修改不可直接發布。學生已開始的私人作答可繼續原案例版本，新發布不偷偷改題；已提交者可開始新版本。學生 API 不回傳原始參考清單；教師提交歷程也不包含它。

正式提交需四階段完整，提交後答案鎖定。T2／T4 只挑該提交每階段最後版本與提交時已請求的對應回饋，私人初稿及其他 revision 的回饋不分享。學生提交前提示教師可讀正式版本及對應回饋。AI 缺席、失敗、過期均不阻擋正式提交，絕不轉成正式成績。

模型呼叫不持有作答列鎖。回饋重新載入只刷新狀態，不重綁編輯中的原始版本；其他分頁已更新時儲存回 409，保留目前文字，可自行保留後重新載入。超過 310 秒的遺留 pending 呈現中斷狀態，重試時回收。每答案版本預設最多 3 次，失敗也計次；可由管理者設 1–10 次，實際修訂後是新答案版本。

A6 的回饋逾時可設 5–300 秒，實際仍取部署 Ollama timeout 與該值較小者，頁面明示部署上限。模型／端點唯讀，不在管理 UI 編輯憑證或覆寫 profile。既有 Breeze／Llama3／Qwen 設定不改；新文字回饋使用新 schema，沿用各自 system 合併、近端要求與 sampling，舊 assessment 契約不變。模板、案例、答案版本與回饋模型／profile／prompt 版本有對應紀錄；不保存原始封包、thinking 或 raw output。

匯出僅限所選課程，CSV 公式開頭會加字元保護、引號轉義；下載留操作稽核，不在日誌複製作答。T3 只有數量統計，不能聲稱代表分析能力、AI 評分準確率或教學成效。
