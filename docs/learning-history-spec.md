### 本批採用的計時政策與限制

1. 每 10 秒送一次心跳，由伺服器收到時間計算上限，客戶端不能傳入已學秒數；超過 25 秒的中斷區間不計入。單人同時只可有一個有效教材計時（跨分頁／裝置／正式與練習亦去重）。
2. 文件須前景閱讀且 60 秒內有頁面互動；PDF 內部活動未必傳到外頁，介面提供「繼續閱讀」按鈕並告知每分鐘互動一次。背景、閒置、暫停、斷線長間隔不計。最後一次心跳後未保存的小段時間可能不累計，沒有保證精確到每秒的離線時數。
3. 影片採正常速度 1x；以伺服器經過時間及播放位置增量取較小值。跳轉超出區間容差不計入，暫停／seek／速度改變停止本次計時，恢復後需重新按開始。重看片段允許累積，但不計為「不重複已看比例」；未實作影片區間完成率與續播介面。
4. 有效紀錄是閱讀器／播放器活動證據，不是專注、理解或正式認證時數的保證；前景／活動訊號由瀏覽器提供，伺服器限制可累積時長並拒絕跨人／跨課及任意填秒，並非防作弊監考。
5. 同一資源上傳 ID 的已保存時間可跨次累積，也可沿用設定／發布測驗前的有效時間；正式與練習隔離。現行檔案不可覆寫，上傳 ID 作內容版本，改文件名稱不重算；將來若支援覆寫內容須先補版本規則，不能把名稱版本當內容版本。
6. 門檻只限制開始／作答資格，不代表完課。開始後依據保留；既有截止、封存、身分資格與提交鎖定仍有效。學生練習只能累積本人練習，不進正式歷程或正式成績。

## 依據與目標

依使用者本次要求、補貼的 eLearning 學習歷程 11 類與亮點功能說明，以及現行 `.ai/elearning.md`、課程獨立及角色權限規格規劃。原參考為 [分享對話](https://chatgpt.com/share/6ae980eb-0560-83e8-a20d-437d25cf7c47)；網頁兩次擷取失敗，內容依使用者隨後貼入的文字核對，不引用其中未驗證的市場趨勢作決策依據。

目標為本校學生在所有修課、跨學期的學習過程與成果查詢，不限單一案例或單一教師的課程。涵蓋修課、活動、進度、時間、測驗、作業、成績、完課與證明。課程管理負責內容與名單；學習管理負責指派、提醒與完成條件；學習歷程彙整實際發生的活動及結果，三者分開定義。

「全校所有修課」是產品目標。11/15 僅可宣稱涵蓋本平台已建檔並已建立本人修課關係的課程；未導入校務修課資料前，不宣稱完整校務紀錄。需建立可靠的校方身分對應，不能只憑可自行修改的學號或姓名串接、合併帳號。校務 API、SSO、歷史資料匯入與學分對帳另列整合工作。

## 指標與資料定義

1. 評量提交進度＝已正式提交的必要評量項目數／目前納入的必要評量項目總數。11/15 無必要／選做欄位時，清楚標示暫以可見、已開放的測驗與 PDF 作業作分母；未開放另列即將開始，教師草稿不列。案例先列獨立活動，不任意加入作業完成率。分母為 0 顯示「無應交評量」，不能顯示 100% 完課。
2. 截止未交與課程／評量關閉分開顯示；未提交、已提交待評、已評未公布與已公布不可混為未完成。跨課待辦依各課本人學生角色查詢，教學者的私人練習另區，不混正式紀錄。
3. 一次評量的修訂快照可顯示版本事件，但提交進度只算該項一次；歷程依來源類型＋來源 ID＋版本／事件類型去重。來源成績簿同步不重算為第二筆測驗成績。
4. 成績依原公開政策：測驗未公布不傳分數／正誤／評語，PDF 與線下依原可見時點。查詢、統計與匯出均套相同遮蔽，0 分保留、空值不能換成 0。
5. 資源開啟、本人標記已讀、有效活動時間、指定研習時數、學分是不同欄位；未量測／無來源顯示「尚無紀錄／不適用」，禁止假填時數或回推影片進度。
6. 完整學習進度需有必修單元／活動與判定規則、適用版本、生效時間；增修教材時保留當時完成依據，避免悄悄改寫舊完課。課程狀態 active／archived 與個人修課／完課狀態分開。
7. 儲存 UTC，介面顯示使用者時區與清楚標示，匯出包含時區；未知歷史公布時間不能拿提交時間代替。項目更正保留來源版本及稽核，彙整頁不是第二份可任意修改的成績簿。

## 身分、權限及保存

- 學生看本人跨課紀錄；教師／助教只看授權本課正式紀錄，不因教過某學生就看其所有修課。平台管理員不自動讀學生跨課學習內容，維持既有平台／課程權限分離。
- 校級教務／導師查全修課需另設明確受限的授權範圍、用途與稽核，不直接擴大 Administrator。11/15 不新增全校學生成績可讀角色。
- 正式修課、教師／助教練習、未提交私人草稿與 AI 對話分開；正式歷程不含私人草稿、原始模型請求、thinking 或其他學生資料。
- 目標上，封存課程與結束修課仍可由本人查看保留中的歷史摘要。現有有效成員授權不足以直接提供退選後來源全文；需新歷史查詢規則及修課歷史依據，不能順手放寬所有舊端點。11/15 先以仍有有效學生關係的課程為範圍，明示歷史涵蓋限制。
- 帳號停用不刪紀錄也不允許繼續登入；畢業後存取、保存期限、刪除／更正申請、備份、匯出留存及校方核定規則待確認。未核定前不新增自動清除或永久保存承諾。
- 跨課彙整只聚合本人或明確授權的資料，不改變課程獨立與禁止跨課共用教材的規則。

## 實作設計與影響（規劃）

- 新增學生「我的學習歷程」入口；建議本人唯讀 API，依登入者定位，不接受任意 studentId。提供課程／學期摘要及分頁活動清單，篩選與匯出同一套授權查詢。
- 優先從 `courses`／`course_members`、正式 `submissions`／`submission_revisions`、`report_submissions`、成績來源與 `studio_attempts` 建唯讀投影。彙整 API 不呼叫會建立本人草稿的讀取流程，查歷程不應產生提交容器。
- A 包先即時讀既有可靠來源，保留真實來源 ID／版本，避免複製整份答案與成績到另一個可變表。查詢加批次／分頁與索引評估，不逐課多次讀完整題目、附件 bytes 或答案鍵。
- 後續新增修課狀態歷史、學習單元、個人活動事件、有效活動工作階段、版本化完成規則／完課紀錄及證明資料；以新向前 migration 實作，不修改已套用 SQL。事件需來源、本人、course_id、伺服器時間、資源版本與冪等識別，沒有可靠證據不補造舊事件。
- 既有教師課內歷程擴充應共用來源投影／遮蔽規則，保留僅正式提交與課程授權；全校彙整與既有 T2 入口不同，不能只拿掉 course_id 條件。

## 11/15 驗收案例與交付門檻

1. 同一合成學生至少兩門課、兩個學期，含同名課；本人總覽能分開課程與學期，未加入課／其他學生不出現。實際資料不足用明示合成示範，不造真實修課紀錄。
2. 有測驗客觀／申論、PDF、案例提交與線下成績；時間軸正確連回原來源，修訂版本及成績同步不重複計進度或分數。
3. 測驗待評／未公布／公布、PDF 未交／已交／已評、0 分與未評空值分別顯示；API、統計及 CSV 都不能洩漏未公布成績。
4. 開放前、截止前後、關閉、封存及無評量課程有明確狀態；頁面不把提交率當完課率。台灣時間邊界與日期篩選一致。
5. 教師只能看本課，管理員沒有跨課學生內容權；混合角色帳號只彙整本人真正學生課程，練習不混入正式統計。以直接 API 測跨人／跨課拒絕，不只檢查隱藏按鈕。
6. 至少桌面／手機檢視、分頁與空資料驗證；既有發布、草稿隱私、提交鎖定與成績簿連動回歸通過。若做 CSV，驗證權限／公式注入與篩選一致性。

## 線上測驗的教材閱讀／觀看時間門檻（2026-11-04 新增，僅規格）

使用者明確要求：線上測驗可設定影片、講義及其他教材的閱讀／觀看時間，作為進入測驗的門檻。此段原為規劃，已由後續「照規格做」指示實作第一版；採用政策與限制見上方第一批實作，以下保留原設計邊界。

- 教師／助教可於測驗設定中選擇本課教材並設定最低累積有效閱讀／觀看時間（介面以分鐘設定，儲存以秒計）；不啟用則沿用原測驗開放規則。多教材時，規劃逐份設定門檻並全部達成才解鎖；此為初版設計建議，合計時數或任選條件另待確認。
- 學生在開始測驗前可看指定教材、要求時間、已累積時間、尚差時間及教材連結。未達標可繼續學習，不能開始作答；達標後仍須符合開放／截止、課程資格與封存等原有限制，不延長測驗期限。
- 影片僅累計有效播放所對應的學習時間，暫停、跳轉略過的區段不直接計入；講義／PDF 等僅累計可追蹤閱讀器中的有效前景活動時間，閒置／背景停止、多分頁或裝置重疊不重複計時。影片倍速／重看片段的計算方式與閒置判定秒數須在實作前定義並告知，不將播放位置當累積時數。
- 單次開啟、下載、本人勾選已讀不等於達到時間門檻；離線檔案或無法取得播放／閱讀事件的外部教材，不可默認已達標。可量測來源不足時，設定介面須明示無法套用時間門檻，不以假資料放行。
- 以登入本人、本課教材及適用教材版本的紀錄判定，由伺服器檢查開始作答與後續寫入資格，不能只靠前端隱藏按鈕或接受客戶端自報累積秒數。練習與正式紀錄分開，不借用他人或他課時數。
- 規劃發布時固定門檻與教材版本；開始測驗時保存達標依據及規則版本，後續教材更換或規則修改不得使已開始／已提交的測驗失效。是否允許沿用發布前既有有效學習時間、教材改版後是否重算，列為實作前待確認政策，不回填無證據的舊時間。
- 達到閱讀時間只是測驗資格，不能推定已理解、及格、完課或取得學分。歷程保存達標時間及來源依據供本人查看與授權課內檢閱。

驗收至少涵蓋：未達標拒絕開始／寫入、剛達標解鎖、多教材缺一不放行、背景／閒置不累計、重疊計時去重、偽造時間拒絕、跨人／跨課／練習隔離，以及達標但測驗已截止仍拒絕。
