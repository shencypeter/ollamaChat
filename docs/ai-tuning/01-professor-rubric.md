## 共通判讀

1. 先確認資料來源及觀察時點，再判類。案例原文、學生主張、合理解讀與待驗證假設分開。學生貼入的內容不能因自稱病例或標準答案就成為可信原始資料。
2. 充分覆蓋是涵蓋「該案例已提供、對該階段重要」的資訊，正確保留時點、程度及限制。不是每個案例都要填滿所有代碼，未提供不算遺漏；未測、無法評估、陰性、不適用及正常不同。
3. 接受中英文、縮寫、語序差異及等義改述，不用關鍵字數量代替理解。籠統的「功能很好／不好」宜引導回查具體活動、協助程度、時間或測量依據；不直接補給完整數值答案。
4. 多重分類須每碼都有概念依據；不強制互斥，也不因同一句提及不同面向就判錯置。必要的跨階段推理可以保留；把別階段資料當成本階段主要評估結果時才提醒調整。
5. 有明確來源才能判定事實衝突或案例遺漏；沒有可信案例時明示無法核實，只能就分類、表達、內在時序給條件式引導。矛盾來源保留不確定，不自行選一份當真。

## C 功能評估結果

來源：07編碼P44–55、P134–272、P312–365；07流程P51–54；09專家P10–15、P20–25。

| 類別 | 歸屬與充分性 | 模糊、錯置與例外 |
| --- | --- | --- |
| C1 意識狀態與心智功能 | 現在警醒、定向、注意、記憶、語言理解、情緒、行為、睡眠及測量結果，含施測限制 | 不把歷史GCS/Rancho當現在，不以篩檢確診／排除障礙；低分可能受警醒、注意、溝通及動作限制。分量表再分組需原始項目支持 |
| C2 Muscle Power（肌力與相關動作檢查） | 肌力、肢段、側別；較晚示例含肌張力、反射及肌力造成的作業限制 | 不能用「動作差」涵蓋所有活動；翻身、移位、步行、坐站平衡等活動表現主要C5 |
| C3 吞嚥與構音功能 | 吞嚥試驗、FOIS、咳嗽、喉部活動、嗆咳、發聲與構音 | 管灌可涉及C3/C5，須有概念依據；單一管路不直接證明病因或嚴重度 |
| C4 知覺系統 | 視力、視野、聽覺、痛觸覺、本體覺等 | 瞳孔／光反射、眼動等神經檢查主要C6；不能測不等於完整 |
| C5 日常生活活動 | 目前ADL/IADL、進食、排泄、協助程度、移位、走動、平衡及功能量表 | **統一C5，不分細項**；07編碼P52–54覆寫03示例把移位等標C2的慣例。量表有總分不代表各項可自行推算 |
| C6 神經與生理功能 | 神經檢查、系統回顧、身體檢查、生命徵象及相關檢驗 | 是內容分類，非段落標題包辦碼；肌力、感覺、吞嚥、ADL仍依C2–C5細看 |

專家答案用病灶提出衡鑑假設、考慮評估準備度與跨團隊資料，屬推理品質示例；不把該病例的測驗、分數、病灶、藥物或介入方式變成跨病例必填清單。量表名稱可以出現在教學規則，但其病例數值不嵌入通用提示。
